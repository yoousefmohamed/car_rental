# تشغيل النظام على macOS (كتطبيق .app / .dmg)

## لماذا لا يمكن إنشاء ملف الـ dmg مباشرة الآن؟
البرنامج يستخدم مكتبة `better-sqlite3` وهي مكتبة "Native" (مكتوبة بلغة C++) يجب تصنيفها/بناؤها
خصيصًا لنظام macOS (ولمعمارية المعالج: Intel أو Apple Silicon M1/M2/M3). هذا البناء **يتطلب جهاز Mac
حقيقي فعليًا** أو خدمة تبني على أجهزة Mac حقيقية — لا يمكن إنتاجه من ويندوز أو لينكس.

الخبر الجيد: قاعدة البيانات (SQLite) تُخزَّن في مجلد بيانات المستخدم الخاص بالنظام تلقائيًا
(`app.getPath('userData')`) لذلك ستعمل بدون أي تعديل على ماك، ولا توجد أي مشاكل متوقعة في تخزين
البيانات بعد البناء الصحيح.

## الحل: بناء الـ DMG تلقائيًا عبر GitHub Actions (مجانًا، بدون امتلاك جهاز Mac)
لقد أضفت ملف أتمتة (`.github/workflows/build-mac.yml`) يقوم ببناء نسختين تلقائيًا على خوادم Mac
حقيقية مجانية من GitHub:
- نسخة لأجهزة Mac بمعالج Intel (x64)
- نسخة لأجهزة Mac بمعالج Apple Silicon (M1/M2/M3/M4) (arm64)

### خطوات التنفيذ:
1. أنشئ حسابًا مجانيًا على https://github.com (إن لم يكن لديك حساب).
2. أنشئ مستودع (Repository) جديد فارغ، خاص أو عام، بأي اسم (مثلاً `car-rental-erp`).
3. ارفع محتويات هذا المجلد بالكامل إلى المستودع. أسهل طريقة بدون Git من سطر الأوامر:
   - افتح صفحة المستودع على GitHub → اضغط "Add file" → "Upload files"
   - اسحب كل الملفات والمجلدات (بما فيها المجلد المخفي `.github`) وارفعها، ثم اضغط Commit.
   - ملاحظة: تأكد أن مجلد `.github/workflows/build-mac.yml` تم رفعه فعليًا (قد تحتاج لرفعه
     بشكل منفصل لأنه مجلد يبدأ بنقطة، أو استخدم GitHub Desktop للرفع الكامل بسهولة).
4. اذهب إلى تبويب "Actions" في صفحة المستودع. ستجد workflow باسم "Build macOS App (DMG)".
5. اضغط عليه ثم اضغط "Run workflow" لتشغيله يدويًا (أو سيعمل تلقائيًا بعد أي رفع جديد).
6. انتظر حوالي 5-10 دقائق حتى تكتمل عمليتا البناء (Intel و Apple Silicon).
7. بعد الاكتمال، انزل لأسفل الصفحة إلى قسم "Artifacts" وستجد:
   - `car-rental-erp-mac-intel-x64` → حمّله لأجهزة Mac القديمة (معالج Intel)
   - `car-rental-erp-mac-apple-silicon-arm64` → حمّله لأجهزة Mac الحديثة (M1 وما بعده)
   - كل ملف مضغوط (zip) يحتوي بداخله على ملف `.dmg` جاهز للتوزيع والتثبيت.

### إذا كان لديك جهاز Mac (ولو مستعار لمرة واحدة):
الطريقة أسرع وأبسط، فقط شغّل من داخل مجلد المشروع في الـ Terminal:
```bash
npm install
npm run build:mac:arm64   # لأجهزة M1/M2/M3/M4
# أو
npm run build:mac:x64     # لأجهزة Intel القديمة
```
سيظهر ملف الـ dmg داخل مجلد `dist/`.

## عند فتح التطبيق لأول مرة على ماك
بما أن التطبيق غير موقّع بشهادة Apple Developer (Code Signing) — وهي شهادة مدفوعة (99$/سنة) —
سيظهر تحذير من macOS Gatekeeper عند أول تشغيل. هذا طبيعي تمامًا لتطبيقات خارج App Store، والحل:
1. بدلاً من النقر المزدوج، اضغط بزر الفأرة الأيمن (Control+Click) على أيقونة التطبيق
2. اختر "Open" من القائمة
3. اضغط "Open" مرة أخرى في نافذة التأكيد
4. من المرات القادمة سيفتح بشكل طبيعي بالنقر المزدوج

## قاعدة البيانات والنسخ الاحتياطي
- قاعدة البيانات تُحفظ تلقائيًا داخل:
  `~/Library/Application Support/نظام تأجير السيارات/database/car-rental-erp.sqlite3`
- يوجد داخل النظام أزرار لفتح مجلد قاعدة البيانات ومجلد النسخ الاحتياطية مباشرة من الإعدادات.
- بياناتك آمنة ومستقلة تمامًا عن أي جهاز آخر — كل جهاز Mac له نسخته الخاصة من القاعدة.
